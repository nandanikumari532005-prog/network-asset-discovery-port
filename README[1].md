# Network Asset Discovery & Port Audit Tool

A simple Flask-based web application for network asset discovery and TCP port auditing.

## Features

- IP address / hostname discovery
- Hostname resolution
- Basic system information
- TCP port audit
- Open/closed port status
- Web-based dashboard

## Technologies

- HTML
- CSS
- JavaScript
- Python
- Flask

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python app.py
```

Open:

```text
http://127.0.0.1:5000
```

## Usage

Enter an IP address or hostname, for example:

```text
127.0.0.1
```

Then use the Port Audit section to check a permitted port range.

## Security Notice

Use this tool only on systems and networks that you own or are explicitly authorized to audit.
